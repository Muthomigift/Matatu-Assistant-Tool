Matatu SACCO Member Assistant

A Python script that answers common SACCO member questions using the Anthropic API. It is built for a SACCO secretary who gets the same WhatsApp questions every week.

What it does

A member's question goes in, and a short, clear answer comes out. It handles three topics:

Balance: explains how a member can get their balance (the tool cannot see individual balances).
Next meeting: gives the date, time, and place.
Membership fees: gives the registration fee, the monthly contribution, and how to pay.
